# v1.2 识别设计与公开资料调研

## 参考资料

本次通过 GitHub 搜索和公开页面查阅以下资料（2026-10-23）。它们是公开说明、社区规则和同类实现，不是经验证的李跳跳本体源码；不宣称复现其私有算法。实现为本项目独立编写，没有复制第三方代码或整包导入规则。

- [李跳跳社区自定义规则](https://github.com/743859910/LiTiaoTiao_Custom_Rules)：可以看到“页面条件 → 目标控件”的组合思路，存在文字、资源 ID、延迟等规则。其文档包含开屏 SDK 控件、`| 跳过` 等例子。社区规则也包含升级、权限弹窗等操作；清屏没有导入这些规则，也不会替用户同意授权。
- [AdSkipHelper](https://github.com/Giftedcat/AdSkipHelper)：公开的仿李跳跳示例，讨论摇一摇开屏广告及无障碍节点文字匹配、点击。这里属于历史示例，不能证明当前每个版本应用都保持同样布局。
- [GKD](https://github.com/gkd-kit/gkd)：公开说明使用选择器、订阅规则与快照审查，支持在指定页面条件下操作节点。参考的是可诊断、条件组合的思路；本次没有加入 GKD 规则解释器、远程订阅或快照上传。

## 中文开屏广告形态与应对

| 形态 | 处理方式 / 边界 |
| --- | --- |
| 图片、视频全屏开屏，右上角只有“跳过” | 不再要求出现“广告”；限定按钮范围、右上角位置、切换应用后的 15 秒窗口 |
| `跳过 5s`、`5秒｜跳过`、`跳过（５秒）` | 归一化空格、全角数字与括号，匹配倒计时格式；也识别紧邻的独立倒计时控件 |
| 摇一摇、扭一扭、滑动跳转 | 可访问文字作为辅助证据，仍需找到跳过按钮；不摇动、不扭动、不点击广告落地页，不拦截陀螺仪或传感器 |
| 无文字按钮，存在 skip / 广告 SDK 资源 ID | 根据资源 ID、按钮位置和窗口条件判断；ID 按边界分词，不再因 download 中包含 ad 就当广告 |
| 按钮动态加载、首次事件中还没有按钮 | 开屏阶段进行有限次数的延迟重试；服务存活时也监听后续内容变化 |
| 纯图片/Canvas/WebView 无节点、视频未到可跳时间 | 可能无法识别或按钮被禁用，日志记录原因；没有 OCR、截图识别、固定坐标盲点能力 |

这些是基于公开资料和常见界面模式设计的启发式规则，不是所有中文 App 的实时广告样本调查。没有实际应用快照时不能保证某个广告可跳过。

## 点击约束与结果

- 系统设置、手机管家、权限页、安装器和清屏自身始终排除；扫描基于当前活动窗口，旧事件与当前窗口不一致时记录切换。
- 每次最多广度扫描 600 个节点，限制深度为 50；截断会记入诊断。忽略隐藏、禁用、输入、密码、越界和过大的候选控件。
- 普通“跳过”需要右上角位置及开屏时间、倒计时、广告或摇动提示之一；隐私/首次使用引导页面有额外排除条件。“关闭”不按普通跳过放宽。
- 明确的广告跳过文字或广告/开屏 SDK 关闭 ID 可以独立提供证据。匹配不等于绝无误触，暂不支持按应用导入自定义规则。
- 优先节点点击，最多向上检查四层，禁止点击整页父容器。普通点击失败后，只有用户开启手势兜底才点已识别节点的中心。
- 一次操作后冷却 1.5 秒，并在 500ms 后检查目标是否仍可见；按钮消失不等于广告已经被确认关闭。窗口切换时记为结果未确认。
- 统计仍是 Android 接受操作的次数，不是经验证成功关闭广告的次数。

## 日志

主界面“打开识别日志”进入独立页面，支持自动刷新、按应用名称/包名/原因搜索、按结果分类、暂停记录、复制筛选结果和清空。

本机最近 250 条记录保存：时间、包名、候选文字（最多 60 字）、资源 ID、边界、规则证据、拒绝/点击/观察结果。重复相同原因三秒内去重。不保存整页文本、截图或输入/密码内容，不上传日志；候选本身仍可能含敏感信息，复制前应检查。

## 验证范围

规则单元测试覆盖无广告字样、倒计时与全角字符、描述文字、摇一摇、邻近倒计时、SDK ID、错误 ID 子串、文字缺失、普通关闭、隐私引导、越界和过大父节点等。已执行 APK 构建与签名检查；没有华为畅享 60 真机，不能宣称设备效果已验证。

`lintDebug` 的 `QueryAllPackagesPermission` 来自原有清单权限，未屏蔽。它与本次新增规则测试和 APK 构建结果分别报告。
